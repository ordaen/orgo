# orgo

## Overview

`orgo` aims to be a Go web/application framework built around a SQL query
builder for PostgreSQL. The goal is to give Go developers a single,
cohesive toolkit for building web applications backed by Postgres, rather
than stitching together separate routing, middleware, and database
libraries.

Planned features include:

- A fluent, type-safe query builder for PostgreSQL
- HTTP routing with route grouping
- A composable middleware chain for cross-cutting concerns (logging, auth, recovery, etc.)
- Structured request/response helpers and input validation
- Simple configuration and application bootstrapping

This describes the project's intended direction, not its current state —
see Status below.

## Status

This project is in early setup and pre-code: it is a brand-new repository
that currently contains only this README and the license. None of the
features described in the Overview have been implemented yet, and no
source code, build instructions, or usage documentation exist.
